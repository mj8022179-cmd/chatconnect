# ChatConnect

A responsive messaging UI built with React and Vite. It includes searchable conversations, message sending, status updates, profile editing, and browser-local persistence.

## Getting started

```sh
npm install
npm run dev
```

Use the navigation rail to switch between chats, status, and your profile. Messages and profile changes are saved in local storage in this browser; no server or account is required.

## Production build

```sh
npm run build
npm run preview
```
